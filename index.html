README — Free Deployment

Deploy free on Cloudflare Pages in 5 minutes

Option A — Direct Upload (no GitHub needed)

  1. Save this file as index.html
  2. Go to dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets (free, no credit card)
  3. Drag & drop the index.html file → Deploy. You get a free *.pages.dev URL instantly
  4. Optional: add your own domain free via Cloudflare DNS

Option B — GitHub (recommended, auto-updates)

  1. Create a free GitHub repo and upload index.html
  2. Cloudflare Pages → Connect to Git → select the repo → Deploy. Every push redeploys free

How to edit (no paid tools)

  • Fast way: Use the Admin panel above (password admin123) to edit services, prices, coupons & branding — saved in the browser free.
  • Code way: Open index.html in any free editor (VS Code / Notepad) and search for DEFAULT_STATE to change prices, or TRANSLATIONS to change text.
  • WhatsApp number: Change it in Admin → Branding, or search for 212681560808 in the code.
